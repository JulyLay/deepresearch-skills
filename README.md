# Скіли Юлії Лайко

Набір AI-скілів для маркетингу та продажів. Кожен скіл — окрема папка з `SKILL.md` (головний файл з YAML-шапкою) і допоміжними файлами методології/шаблонів.

## Скіли

| Скіл | Що робить |
|---|---|
| [dnk-klienta](dnk-klienta/) | Глибинний 5-частинний аналіз ЦА та психології покупця + режим матриці сегментів |
| [hunt-ladder](hunt-ladder/) | Аналіз продукту через 6 рівнів усвідомленості Ханта + стратегія запуску |
| [hormozi-offer](hormozi-offer/) | Створення невідпорних оферів за методологією $100M Offers Алекса Хормозі |

## Як використовувати в Claude Code

Скопіюй потрібну папку скіла у директорію скілів Claude (наприклад `~/.claude/skills/`):

```bash
cp -r dnk-klienta ~/.claude/skills/
```

Або підключи весь набір як плагін / завантаж файли в Claude Project Knowledge.

## Структура скіла

```
skill-name/
├── SKILL.md          # головний файл: YAML-шапка + алгоритм роботи
├── methodology.md    # детальна методологія
└── ...               # шаблони, частини, керівництва
```
