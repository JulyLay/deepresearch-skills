# Шаблоны Instagram DM-бота

## ⚠️ Гендерно-нейтральный текст — обязательно

Все шаблоны и кнопки — без гендерных глаголов и косых черт «(а)». Кнопка «Я подписался(ась)» — НЕТ. Кнопка «Готово, проверь» / «Проверить подписку» — ДА.

Если в примере ниже встречается гендерный глагол («сделал», «закинула», «забрала») — это материал для идеи и структуры, а не для копипасты. Финальный текст всегда переписывается в нейтральную форму.

---

## Принципы Instagram DM

- Короче, чем Telegram — в Instagram читают быстро
- Первое сообщение: вызвать желание получить лидмагнит и подписаться
- Второе сообщение (подписка подтверждена): перевести с высокой конверсией на следующий шаг
- Кнопки — ключевой элемент. Текст кнопки = очевидное действие, без гендера
- Пиши триггерно, цепляюще, но без лишних букв, краткими цепляющими фразами

## Сообщение 1 — Первоначальный контакт

Отправляется: сразу после того, как пришло кодовое слово

### Структура
1. Цепляющий триггерный заголовок (1 строка — не «привет», а что-то по теме)
2. Тизеры, что именно внутри лидмагнита. Не «узнаешь всё про агентов» — а конкретная механика, кейс, результат
3. Один шаг до получения: подписаться на аккаунт
4. Кнопка

### Шаблон А (энергичный)
```
Здесь всё про [тема лидмагнита коротко]

Внутри:
→ [конкретный инсайт 1 из лидмагнита]
→ [конкретный инсайт 2 из лидмагнита]
→ [конкретный инсайт 3 из лидмагнита]

Чтобы забрать — подпишись и жми кнопку ниже 👇

[Кнопка: Готово, проверить ✅]
```

### Шаблон Б (история/шок)
```
[Живая зацепка — результат, который удивит. Пример: «В шоке от того, что сейчас делает мой ИИ-агент»]

[2–3 строки — что конкретно происходит, с числами]

Всё это доступно прямо сейчас — держи ссылку на материал.

Один шаг: подпишись и жми кнопку ниже 👇

[Кнопка: Проверить подписку ✅]
```

### 🥇 Золотой стандарт (пример А — лаконичный)
```
Здесь всё про нейросеть, которая помогает анализировать контент, собирать карусели и писать тексты без шаблонов

[Кнопка: Открыть материал]
```

### 🥇 Золотой стандарт (пример Б — шок + список результатов, переписано в нейтраль)
```
Честно, тут шок (мягко выражаясь)

Смотри что только что выдал мой ИИ-агент по контенту.

В него ушла транскрипция одного зума.
Через час там было готово:
﻿﻿6 сценариев для Reels
﻿﻿2 карусели с готовыми текстами для карточек
﻿﻿3 коротких поста
﻿﻿2 длинных поста
﻿﻿2 серии Stories
﻿﻿8 цитат
﻿﻿1 статья

Итого: 16 единиц контента из одной транскрипции — полностью сам.

[Кнопка: ИИ-агент тут]
```

### 🥇 Золотой стандарт (пример В — провокационный вопрос + кнопка)
```
Как сделать 50k аудитории с 1 рилс?
Стратегия как набирать аудиторию в 2026 году

Жми на кнопку чтобы забрать 👇

[Кнопка: Получить]
```

### 🥇 Золотой стандарт (пример Г — личный ассистент, «только представь»)
```
Пора собрать своего ИИ-ассистента, который пишет под твой стиль речи (или докрутить, если он работает криво)

Только представь:
...он заменит 1000 попыток заставить ИИ перестать писать шаблонную херню.
...он будет множить твои мысли в разы быстрее — несколько соц.сетей, меньше времени.
...он будет на связи 24/7 — твоя правая рука, без повторных объяснений.

Все инструкции в моём тг-канале, забирай

[Кнопка: Создать ИИ-ассистента]
```

## Сообщение 2 — Подписка подтверждена ✅

Отправляется: когда бот проверил и видит подписку

### Структура
1. Подтверждение подписки (1 строка)
2. **3 буллита с тизерами** — другие углы, чем в сообщении 1
3. **Личная строка от автора** — почему этот материал важен (1 предложение, без пафоса, в настоящем времени)
4. Ссылка на Telegram-бот
5. Короткий призыв открыть

### Шаблон А
```
Забирай [название] по кнопке ниже.

Внутри:
→ [тизер 1 — другой угол, чем в сообщении 1]
→ [тизер 2]
→ [тизер 3]

[Личная строка: почему этот материал важен — в настоящем времени, без гендера]

Открывай в Telegram 👇

[Кнопка: Получить в Telegram]
```

### Шаблон Б (лаконичный)
```
[1 провокационный вопрос в теме автора, например «как набирать аудиторию в 2026 году» или «как собрать ИИ-ассистента, который освобождает 3 часа в неделю»]

Вижу подписку, забирай [инструкцию / видео / гайд]
👇

[Кнопка: Открыть материал]
```

## Сообщение 3 — Не подписан ❌ (первая проверка)

Отправляется: когда бот проверил и подписки нет

### Шаблон А
```
Подписки пока не видно...

Подпишись и жми кнопку снова — проверю ещё раз 👇

[Кнопка: Готово, проверь]
```

### Шаблон Б (мягкий)
```
Хм, подписка пока не отображается.

Зайди на мой аккаунт → подпишись → вернись и нажми кнопку ниже.

[Кнопка: Готово, проверь]
```

## Сообщение 4 — Не подписан ❌ (повторная проверка)

Отправляется: когда кнопка нажата повторно, но подписки всё ещё нет

### Шаблон А
```
Всё ещё не видно подписку.

Иногда Инстаграм показывает с задержкой — попробуй через минуту 🙏

[Кнопка: Проверить ещё раз]
```

### Шаблон Б (с помощью)
```
Что-то не срабатывает 🤔

Иногда нужна пара минут. Попробуй:
1. Зайди на мою страницу
2. Убедись, что подписка активна (кнопка «Подписан»)
3. Вернись и нажми ниже

[Кнопка: Готово, проверь]
```

## Советы по настройке DM-бота

**Кнопки:** Не более 1–2 кнопок на сообщение. Один выбор = меньше трения. Текст кнопки — нейтральный, без «(а)».

**Триггеры:** Настрой реакцию на кодовое слово в любом регистре (АГЕНТ / агент / Агент).

**Задержки:** Не нужны в первых сообщениях. Бот отвечает мгновенно.

**Дополнительные триггеры для Сообщения 2:** Некоторые платформы (Manychat, BotHelp) позволяют автоматически нажимать «Проверить подписку» через N секунд после Сообщения 1 — это улучшает конверсию.
